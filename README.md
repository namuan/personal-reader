# Personal Reader

A private, read-only iPhone app that downloads text-focused Reddit posts from
subreddit feeds or authenticated private listings, stores them locally in SQLite,
and supports offline reading with read/unread tracking. Built for personal
deployment on the owner's iPhone.

## Architecture

```text
PersonalReaderApp (iOS 17+, Swift 6, SwiftUI)
└── PersonalReaderCore (local Swift package)
    ├── Models          Story, SyncState
    ├── Networking      FeedConfiguration, RedditFeedClient
    ├── Parsing         RedditRSSParser, HTMLSanitizer
    ├── Persistence     StoryRepository (GRDB/SQLite), DatabaseLocation
    ├── Security        KeychainTokenStore, PreferencesStore
    └── Sync            StorySyncService (throttle, backoff, retention)
```

Key behaviors:

- The RSS token is stored only in the Keychain with
  `kSecAttrAccessibleAfterFirstUnlockThisDeviceOnly`; username, subreddits, and
  setup state live in UserDefaults. No token ever appears in the database,
  logs, or backups.
- Sync state (last successful sync, 429 backoff deadline, attempt count) is
  durable in the `sync_state` table, so relaunching the app cannot bypass the
  30-minute minimum interval or an active rate-limit backoff (1, 2, 4, 8, 16,
  30-minute exponential schedule, honoring `Retry-After`).
- Each request stores at most 50 stories and preserves read state on refresh.
  The end of the story list provides a Load older stories control that follows
  Reddit's authenticated pagination cursor until there are no more entries.
  Subreddit stories older than 14 days are removed; private listings retain the
  entries Reddit returns so older saved posts remain browsable.
- The feed menu browses configured subreddits plus Front page (Best, Hot, New,
  or Rising), Saved, Upvoted, Downvoted, Hidden, Submitted, and Comments
  private listings. Swipe the Front page header left or right to change its
  sort.
- Stories are presented as offline-readable cards with a preview and a separate
  action to open the original Reddit post in the browser.
- Feed HTML passes through an allowlist sanitizer (scripts, styles, iframes,
  event handlers, and JavaScript URLs removed) and renders through a native
  attributed-string path with no JavaScript.

## Development workflow

```sh
make resolve      # fetch dependencies (GRDB 7.x, pinned in Package.resolved)
make format       # format Swift sources
make check        # lint + build + tests (quality gate; run before device builds)
make project      # regenerate PersonalReaderApp.xcodeproj from project.yml
make app-build      # compile the iOS app for the simulator
make app-install    # install + launch on a booted simulator
make device-install # build, sign, install + launch on a connected iPhone
make open           # open the package in Xcode
```

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `project.yml`. Edit `project.yml`, not the `.xcodeproj`, when changing the
target.

## Deploying to your iPhone

1. Open `PersonalReaderApp.xcodeproj` in Xcode.
2. Select the **PersonalReaderApp** target → Signing & Capabilities.
3. Choose your Apple ID's **Personal Team** (or a paid development team) and a
   unique bundle identifier if `com.example.personalreader` is taken.
4. Connect your iPhone (Developer Mode enabled), select it as the run
   destination, and Run with the Debug configuration.
5. Approve the developer identity on the phone if iOS asks.
6. In the app: enter your Reddit username and private RSS token from
   <https://reddit.com/prefs/feeds>, then choose either subreddits or a private
   listing. Use **Test connection** before saving.

After completing the one-time Xcode account and trust setup, command-line device
installation is available:

```sh
make device-install
```

The command auto-detects the first connected iPhone and first Apple Development
team, builds with automatic provisioning, installs with `devicectl`, and launches
the app. Override detection when needed:

```sh
make device-install DEVICE_ID=00008110-... TEAM_ID=ABCDE12345
make device-install APP_BUNDLE_ID=com.example.personalreader
```

If Xcode reports `No Account for Team`, add the Apple ID under Xcode Settings →
Accounts and run the app once from Xcode so it can create the provisioning
profile. Keep the iPhone connected, unlocked, trusted, and in Developer Mode.

A free Personal Team provisioning expires after about seven days — rerun
`make device-install` when it does. For a longer-lived install use a paid
membership (development or Ad Hoc build).

Before calling it done: archive the Release configuration (Any iOS Device →
Product → Archive), let Xcode validate it, and run the physical-device smoke
test against that build.

## Testing the feed before first run

Phase 1 of the plan requires validating the live private feed outside the app:

```sh
TOKEN="..." USER="..."   # never commit these
curl -A "ios:PersonalReader:v1.0.0 (by /u/$USER)" \
  "https://www.reddit.com/r/shortstories/.rss?feed=$TOKEN&user=$USER" | head -40
```

Confirm the item names, date format, and HTML structure, then save a redacted
copy as a parser fixture. If Reddit no longer serves the private feed,
development stops until an approved data source is chosen.
